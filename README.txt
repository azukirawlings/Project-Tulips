Project Tulips · Windows
========================

Double-click Project Tulips.exe to open the tactical map on this PC. Node and other runtimes are not required.
Basemaps (dark, light, hillshade, satellite) need a network connection. Units, forts, lines, and place names are stored in the browser on this computer.

Starting it
1. Unzip the archive into any folder. Don't run the program from inside the zip.
2. Double-click Project Tulips.exe.
3. A window titled Project Tulips stays open, and the browser opens on its own.
4. Close that window when you're finished. The program exits with it. Leave the window open while you use the map.

If Windows says "Windows protected your PC"
The file isn't signed by Microsoft, so this warning shows up. That doesn't mean the file is corrupt.
Click More info, then Run anyway.
If antivirus blocks it, allow the file or add an exception.

If the browser doesn't open
Copy the address shown in the window into Chrome or Edge.

Saving
Changes are kept automatically. Keep using the same browser.
Moving to another computer or browser, or making a backup: open Sandbox (the button labeled 沙盘), export JSON, then import that file in the new place.

System
64-bit Windows 10 or later.

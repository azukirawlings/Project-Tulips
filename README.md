# 阵图

本地战术沙盘。底图保持干净，自己画部队、箭头、区域和战线，数据留在浏览器里。

## 能做什么

- 标点、画线、多边形、曲线、箭头、徒手、圆和量距
- 陆海空分开记现有和满编，编制可以自己加
- 查看和编辑两种模式
- 把当前局面记成时间点，再拿来对照
- 阵营、颜色、上下级可以改
- 导出、导入 JSON，单位图片和说明会一起带走

## 开发

需要 Node.js 20 以上。

```bash
npm install
npm run dev
```

地图瓦片用的是公开服务，不需要钥匙。

## Windows 单文件

装好 Go 之后：

```bash
npm run build
cd desktop
go build -ldflags="-s -w" -o 阵图.exe .
```
